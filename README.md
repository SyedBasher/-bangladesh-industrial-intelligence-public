# Bangladesh Industrial & Factory Intelligence

**Mangrove Intelligence | Public product preview**

This repository contains a small, independently maintained **public-facing shell** for Bangladesh Industrial & Factory Intelligence, an evidence-based industrial research and data product for Bangladesh.

## Preview

Open [index.html](index.html) in a browser to view the standalone interface prototype. All example factories, company names and displayed statistics are **synthetic illustrations**. They must not be interpreted as verified business information, national totals, investment advice, or live observations.

The preview is copied **without layout, typography or functionality changes** from the established v0.25 development checkpoint. It does not contact a production API.

## What the product is intended to cover

The future product combines an official DIFE/LIMA establishment backbone with carefully scoped organization identities, lawful external-source evidence, industrial geography, validation-controlled national views, and longitudinal factory/company disclosures. Where defensible, future modules may describe physical capacity, production, investments and commissioning history, energy/FX constraints, and explicitly documented technology adoption.

Coverage is not prevalence; district-level context is not a site-specific event; company facts must not be represented as plant facts. Missing evidence never means that an activity or risk is absent.

## Public repository boundary

Only approved public explanations, synthetic previews, public-facing contracts and their isolated tests belong here. This is **not** the engineering, source-archive, or customer-data repository.

No working database, real establishment extract, private source archive, coordinates, credentials, internal audit or nonpublic methodology is permitted. See [docs/DATA_POLICY.md](docs/DATA_POLICY.md).

This repository has its own Git history. It is **not** a fork or mirror of the canonical engineering repository.

## Validation

The public GitHub Actions workflow runs small, dependency-free checks for this public shell only. A green public build **does not** validate the private data pipeline, source truth, migrations or real-world record matching.
